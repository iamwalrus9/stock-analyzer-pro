# MyStockQuant 3.0

기존 2.0 대시보드와 백테스트를 유지하면서 **한미 주식 100종목 스캐너와 랭킹**을 추가했습니다.

## 설치/배포

GitHub 저장소의 루트에 `app.py`, `scanner.py`, `requirements.txt`, `README.md` 네 파일을 업로드하고 Commit changes를 누릅니다. Streamlit Cloud의 Main file path는 `app.py`입니다.

## 사용

1. 웹앱에서 `🏆 한미 종목 랭킹` 탭을 엽니다.
2. 미국 50/한국 50/한미 100종목을 선택합니다.
3. `전체 종목 스캔 시작` 버튼을 누릅니다. Yahoo Finance의 요청 제한 시 일부 또는 전체 데이터가 실패할 수 있습니다.
4. 현재 신호 종목, 근접 종목, 과거 신호 발생 횟수, 백테스트 완료 거래 및 실패 종목을 확인합니다.
5. 전략 조건을 바꾸면 다시 스캔해야 합니다.

**주의:** 순위 점수는 현재 조건 충족 정도에 대한 설명용 휴리스틱입니다. 미래 수익률 예측이나 투자 추천이 아닙니다. 고정 종목 목록은 생존자 편향이 있으므로 후속 단계에서 당시 시점의 구성 종목으로 재검증해야 합니다.
